# naufalabdul11.github.io

Source of my portfolio website. It is a static site that GitHub Pages serves as is, with no build step.

- `index.html`: the whole site (markup, styles and scripts); views are addressed after `#`, for example `#projects/thesis`
- `i18n/`: translations (Indonesian, Chinese, Russian, German), loaded only when that language is chosen
- `data/`: sample data for the interactive models, loaded only when a model is opened
- `img/`, `fonts/`, `files/`: images, self-hosted fonts and the resume PDF
- `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll`: hosting files
